# Requisitos del Sistema: UniPulse Cartagena

## 1. Objetivo
Desarrollar una aplicación web interactiva tipo dashboard para estudiantes universitarios, enfocada en la gestión de eventos del campus, torneos deportivos (liga de fútbol y porteros) y proyectos de tecnología estudiantiles.

## 2. Requisitos Funcionales
- **RF1: Layout General:** Barra lateral de navegación, cabecera con estadísticas rápidas (usuarios activos, torneos, proyectos) y tema oscuro moderno (estilo neón/tecnológico con paleta midnight navy y acentos cyan).
- **RF2: Módulo de Torneos:** Listado de partidos universitarios con estados (En vivo, Programado, Finalizado) y marcador interactivo.
- **RF3: Módulo de Proyectos Estudiantiles:** Tarjetas de proyectos con filtros por categoría (IA, Web, Hardware/IoT) y contador de "Me gusta".

## 3. Requisitos No Funcionales
- Stack tecnológico: React (Vite) + Tailwind CSS + Lucide Icons.
- Componentes modulares y código limpio, listo para producción.
